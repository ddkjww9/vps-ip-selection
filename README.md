## 选型就看两个指标：IP属性和线路质量

IP决定账号安全，线路决定使用体验，两者互不替代，下单前分别确认。

### IP：原生、类型、纯净度

原生IP指IP所在地与注册地一致，也就是直接从互联网服务提供商拿到的地址，和广播IP相对。IP类型分三种：ISP是住宅IP，business是商业IP，hosting是机房IP。海外社媒运营认准**原生住宅（ISP）IP**，这是账号能不能从平台拿到流量的关键变量之一。

自查只需要30秒：打开 ipinfo.io，页面上有两处country字段，一致即为原生IP；type字段会显示这个IP属于isp、business还是hosting。不管从哪家买VPS，都可以先这么验一遍。
